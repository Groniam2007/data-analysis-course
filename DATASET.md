# Паспорт набора данных

## Общие сведения

| Параметр | Значение |
|---|---|
| Наименование | GeoNames (географические объекты мира) + показатели здоровья и развития стран |
| Источники | GeoNames geographical database (geonames.org, выгрузка allCountries, даты изменения 1993–2017); World Bank: World Development Indicators (data.csv, 1960–2015) и сводные показатели здоровья (health_indicators.csv, 2000–2024) |
| Файлы | `data/raw/geonames.csv` — 1404,5 МБ; `data/raw/data.csv` — 42,9 МБ; `data/raw/health_indicators.csv` — 1,6 МБ |
| Формат | CSV, разделитель «,», без экранирования кавычками; кодировка UTF-8; переводы строк LF |
| Объём | geonames: 11 540 325 записей × 19 столбцов; health: 5 275 × 48 (211 стран × 25 лет); WDI: 89 010 × 60 (258 стран и агрегатов × 345 индикаторов, годы в столбцах) |
| Связь файлов | код страны: ISO 3166-1 alpha-2 в geonames, alpha-3 в health и WDI — соединение через справочник стран |

## geonames.csv — основной набор

| Столбец | Смысл | Тип значений | Пригодность |
|---|---|---|---|
| geonameid | идентификатор объекта | целое, уникально, до 11,7 млн | ключ |
| name | название (UTF-8) | текст до 151 символа | да |
| asciiname | название латиницей | текст, 115 пропусков | да |
| alternatenames | альтернативные названия через «;» | текст до 9 760 символов, 52 % пропусков | да, после разбиения в отдельную таблицу (1НФ) |
| latitude, longitude | координаты WGS84 | дробное, 5 знаков | да |
| feature class | класс объекта (A, H, L, P, R, S, T, U, V) | категория, 9 значений | да |
| feature code | код типа объекта (PPL, STM, MT…) | категория, 666 значений | да |
| country code | страна ISO2 | категория, 253 значения; «NA» — Намибия | да |
| cc2 | альтернативные страны через «;» | текст, 97 % пропусков | да, после разбиения в таблицу (1НФ) |
| admin1–admin4 code | коды административного деления | строка с ведущими нулями | ограниченно: нет справочника названий |
| population | население | целое до 6,8 млрд; 0 у 95,7 % = скрытый пропуск | да, после замены 0 на пропуск |
| elevation | высота по данным источника, м | целое, 80 % пропусков | ограниченно |
| dem | высота по цифровой модели рельефа (SRTM), м | целое; −9999 = «нет данных» | да |
| timezone | часовой пояс IANA | категория, 425 значений | да |
| modification date | дата последнего изменения записи | дата 1993-09-24 … 2017-08-29 | да |

## health_indicators.csv

Ключ — пара `country_code` (ISO3) + `year`. Атрибуты страны `country_name`, `region`,
`income_level` от года не зависят. 43 числовых показателя: население и прирост, ожидаемая
продолжительность жизни, смертность, расходы на здравоохранение, вакцинация, доступ к воде,
ВВП на душу населения. Пропусков много в показателях обследований (stunting, wasting,
prenatal care); `obesity_pct` пуст целиком и удаляется.

## data.csv (World Development Indicators)

Широкий формат: `Country Name`, `Country Code` (ISO3), `Indicator Name`, `Indicator Code`
и по столбцу на каждый год 1960–2015, плюс пустой столбец из-за запятой в конце строки.
Содержит 52 агрегата (Arab World, Euro area и т. п.), которые не являются странами.

## Обнаруженные дефекты (план очистки)

1. Нет экранирования, символ `"` внутри названий — чтение с отключёнными кавычками.
2. `NA` — код Намибии, а не пропуск.
3. Без схемы admin-коды читаются как числа и теряют ведущие нули.
4. Скрытые пропуски: `population = 0`, `dem = -9999`.
5. Списки в одной ячейке (`alternatenames`, `cc2`) — нарушение 1НФ.
6. 2 761 запись — повторы одной сущности под разными `geonameid`.
7. Краевые и повторные пробелы, пустые элементы списков, 20 записей без названия.
8. Выбросы: население в миллиарды у гор и рек; расхождение `elevation` и `dem` больше 1 км.
9. 196 значений `elevation` похожи на футы.
10. Разные системы кодов стран и устаревшие коды CS, YU, AN, XK.
11. Краевые пробелы в `region`; пустой столбец `obesity_pct`.
12. WDI в широком формате с агрегатами регионов.
